# DENT_devops — Стоматологическая клиника

REST API сервис стоматологической клиники, упакованный в Docker-контейнер.

Сервис позволяет получать информацию о клинике, расписании и статусе работы.

Технологии:
- Java 17
- Docker

Структура проекта:
DENT_devops/
├── src/
│   └── App.java     # исходный код приложения
├── Dockerfile       # инструкции сборки Docker-образа
└── README.md        # документация проекта
